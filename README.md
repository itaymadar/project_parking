the project is a smart parking management system.
the system allows a parking security guard to view images of vehicles entering the parking lot.

the Services:
*nginx*: Hosts the Web Dashboard.
*apache: Stores* and serves vehicle images
**Docker Compose:** manages and runs the containers.

*the project goal**:
To build a containerized microservices environment for managing and displaying vehicle images.

##Technologies:
*Linux*
*Docker*
*Docker Compose*
*Nginx*
*Apache*
*HTML and CSS*
