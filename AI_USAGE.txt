# שימוש בבינה מלאכותית בפרויקט Smart Parking

במהלך פיתוח הפרויקט נעזרנו בכלי בינה מלאכותית לצורך למידה, תכנון, כתיבת
קוד, הגדרות תשתית ואיתור תקלות.

## באילו חלקים נעזרנו ב-AI

-   תכנון וחיבור בין שירותי Nginx ו-Apache באמצעות Docker Compose.
-   הבנת אופן העבודה של Docker Volumes ושמירת תמונות גם לאחר עצירת
    Containers.
-   הגדרת Nginx כ-Reverse Proxy להעברת בקשות לשרת Apache.
-   הגדרת Apache להצגת רשימת קבצים מתוך תיקיית התמונות.
-   פיתוח מנגנון JavaScript שמקבל את רשימת התמונות ומציג אותן בדשבורד
    באופן דינמי.
-   איתור תקלות ובדיקת תקינות השירותים באמצעות פקודות Docker ו-curl.
-   יצירת תהליך CI באמצעות GitHub Actions לבניית תמונות Docker.

## דוגמאות לפרומפטים שנעזרנו בהם

הדוגמאות הבאות מייצגות את סוג הבקשות שהופנו לכלי AI במהלך העבודה:

-   איך לחבר בין Nginx ל-Apache באמצעות Docker Compose?
-   איך להגדיר Docker Volume כך שתמונות מתיקייה מקומית יהיו זמינות בתוך
    Container?
-   איך להגדיר Nginx כ-Reverse Proxy עבור שרת Apache?
-   איך להציג באתר באופן דינמי תמונות שנמצאות בתיקייה בשרת Apache?
-   איך לבדוק אם שירותי Docker פועלים ואם ניתן להגיע אליהם דרך Nginx?
-   איך ליצור GitHub Actions Workflow שבונה את שירותי Docker בכל Push?

## דוגמה לטעות או להכוונה לא מדויקת של AI ולתיקון שלה

במהלך העבודה על שמירת התמונות, ההסבר הראשוני לא הבחין מספיק בין Docker
Volume רגיל לבין Volume שמחובר לתיקייה מקומית באמצעות Bind Mount.

כאשר מחברים Volume לנתיב בתוך Container, התוכן שהיה קיים באותו נתיב עלול
להיות מוסתר על ידי תוכן ה-Volume. לכן, העתקת תמונות לתיקייה המקומית לא
בהכרח תגרום להן להופיע בשרת Apache.

### כיצד תיקנו את הבעיה

בדקנו את מבנה התיקיות ואת הגדרות Docker Compose, ולאחר מכן שינינו את
הגדרת ה-Volume כך שיהיה Named Volume שמבוסס על Bind Mount באמצעות
`driver_opts`.

ה-Volume מחובר לתיקייה המקומית:

`/home/itaym/projects/smart-parking/storage/images`

כך Apache יכול לגשת לתמונות שנמצאות בתיקייה המקומית, והשינויים בה
משתקפים גם בתוך ה-Container.

בדקנו את התוצאה באמצעות פקודות Docker ובדקנו שהקבצים אכן מופיעים בתיקיית
התמונות של שרת Apache.

## בדיקה ואחריות על התוצאה

השתמשנו בתשובות ה-AI ככלי עזר ולא קיבלנו אותן באופן אוטומטי. בדקנו את
ההגדרות בפועל באמצעות Docker Compose, פקודות `docker compose`, פקודות
`curl` ובדיקה בדפדפן.

הקוד וההגדרות נבדקו ותוקנו בהתאם לתוצאות שהתקבלו בסביבת הפרויקט.
